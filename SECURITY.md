# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Include what you found, the steps to reproduce it, and the impact you expect.

I aim to reply within a few days and to fix confirmed issues as quickly as I can. Please give me reasonable time to fix a problem before sharing details publicly.

## Scope

In scope: the application code in this repository and the live site linked in the README.

Out of scope: denial-of-service testing, social engineering, and reports about items already listed under "Known limitations" in the README.

## Supported versions

Only the latest version on the `main` branch is supported.
